# Таблица лидеров для сайта сервера

Документ для сессии сайта: что Path-of-craft-tree (дальше PCT) пишет для таблицы лидеров и как это читать. Сам сайт PCT не трогает.

## Согласие игрока

В таблицу попадает только тот, кто сам согласился:

- `/pct leaderboard on` — показывать мои уровни на сайте;
- `/pct leaderboard off` — убрать меня из таблицы;
- `/pct leaderboard` — узнать, в таблице ли я.

По умолчанию игрока в таблице нет. Файл сам хранит согласие: строка игрока появляется по `on` и исчезает по `off`, и в обоих случаях файл переписывается сразу. Других игроков, их имён и UUID в файле нет.

## Где лежит

`<мир>/path_of_craft_tree/leaderboard.json`, рядом с профилями игроков. На tidewill и стенде мир — папка `world` в папке сервера. Файл пишется через временный файл и переименование, поэтому читатель никогда не видит половину файла. Файла нет, пока никто не согласился.

## Когда обновляется

- сразу при `/pct leaderboard on` и `off`;
- на периодическом сохранении сервера, раз в минуту (1200 тиков), если у кого-то из согласившихся игроков в сети изменились уровни или имя;
- игрок не в сети остаётся в таблице с последними уровнями.

Сайту достаточно перечитывать файл раз в минуту или реже.

## Формат, версия 1

```json
{
  "v": 1,
  "updated": 1763208000,
  "max_level": 75,
  "branches": {
    "alchemy": "Алхимик",
    "archery": "Стрелок",
    "mining": "Шахтёр"
  },
  "players": [
    {
      "uuid": "0123abcd456789ef0123456789abcdef",
      "name": "Steve",
      "levels": { "alchemy": 0, "archery": 12, "mining": 31 },
      "total": 43,
      "general": 6,
      "updated": 1763207940
    }
  ]
}
```

В примере сокращён список ветвей. В настоящем файле в `branches` и в `levels` каждого игрока все 16 ветвей дерева.

| Поле | Что значит |
| --- | --- |
| `v` | Версия формата. Растёт только при несовместимой смене. Новые поля добавляются без смены версии, незнакомые поля читатель пропускает |
| `updated` | Когда файл записан, секунды Unix (UTC) |
| `max_level` | Предел уровня ветви, сейчас 75 |
| `branches` | Ветви дерева: id и русское название, как в игре. Порядок — по id |
| `players` | Согласившиеся игроки, по убыванию `total`, при равенстве по имени |
| `players[].uuid` | UUID игрока, 32 шестнадцатеричные цифры без дефисов |
| `players[].name` | Имя игрока, каким сервер видел его в последний раз |
| `players[].levels` | Уровень каждой ветви, от 0 до `max_level` |
| `players[].total` | Сумма уровней всех ветвей, от 0 до 16 × `max_level` |
| `players[].general` | Уровень общей шкалы |
| `players[].updated` | Когда строка игрока пересчитана, секунды Unix (UTC) |

Уровни считаются от опыта, а не от изученных узлов, поэтому сброс дерева их не меняет. Команды администратора (`/pct admin`) уровни меняют, и таблица это покажет на следующем сохранении.

## Чего сайту не делать

- Не писать в этот файл. PCT перепишет его при следующем изменении.
- Не показывать игроков, которых нет в файле, даже если сайт знает их из других источников.
- Если файл не читается как JSON, показывать прошлую версию: PCT пишет файл целиком, следующий будет целым.

## Проверка

Разбор и запись строк покрыты тестами (`lib.rs`, тесты `leaderboard`), код — `board_rules.rs` и `leaderboard.rs`. Проверка в игре: зайти, ввести `/pct leaderboard on`, убедиться, что файл появился и в нём ваша строка, затем `/pct leaderboard off` — строка исчезла.
