# Path-of-craft-tree: дизайн мода

Дата: 2026-11-10, обновлено 2026-11-11. Статус: все шестнадцать ветвей обсуждены и реализованы, дерево проверено в игре (раздел 9). Разделы 2–5 описывают замысел. Где реализация от него отходит, это записано в разделах 9–11.

## 1. Идея

Игрок получает опыт в направлении за то, что им занимается: кирка качает шахтёра, лопата копателя. Уровень направления немного усиливает персонажа в этой сфере и приносит очки для огромного дерева пассивных умений в духе Path of Exile.

Мод состоит из клиентской и серверной половин и вырос из прототипа окна дерева на 13 узлах. Сервер принимает все решения, клиент только показывает дерево и отправляет запросы. Игрока без нужной версии мода сервер отключает.

Технический идентификатор мода: `path_of_craft_tree`. Название для игроков: Path-of-craft-tree.

## 2. Направления

Шестнадцать направлений в четырёх секторах дерева. Значения опыта указаны для первого баланса и живут в файле данных, поэтому меняются без пересборки.

### Сектор «Добыча»

**Шахтёр** (`mining`). Ветвь обсуждена. Опыт идёт только за кирку, только по блокам, которые игрок не ставил сам, и только если блок действительно выпадает. Шёлковое касание и удача на опыт не влияют.

| Блок | Опыт |
| --- | --- |
| Незерак | 0,25 |
| Камень, андезит, диорит, гранит, туф, базальт, чернокамень, эндерняк | 0,5 |
| Глубинный сланец | 1 |
| Незерская золотая руда | 3 |
| Медь, незерский кварц | 4 |
| Уголь | 5 |
| Железо, редстоун | 8 |
| Лазурит | 12 |
| Обсидиан, золото | 15 |
| Алмаз | 50 |
| Изумруд | 60 |
| Древние обломки | 150 |

Уровень ветви даёт +0,2% скорости кирки за уровень. Малые узлы всей ветви в сумме дают: скорость кирки +15%, шанс не потратить прочность +20%, шанс лишней руды +12%, опыт Minecraft с руды +30%.

| --- | --- | --- |
| Жила | Руда ломается цепочкой до 8 блоков, прочность тратится за каждый | Прочность за блок ×0,75, ×0,5, ×0,25; цепочка до 12, затем до 16 |
| Забой | Переключаемый режим копания 3×3, прочность ×2 | Прочность ×1,5, затем ×1,2 |
| Рудный нюх | Подсветка руды в радиусе 6 блоков на 10 секунд, с перезарядкой | Радиус 8, затем 10; перезарядка короче |
| Переплавка | Железо, медь и золото падают сразу слитками | Шанс лишнего слитка 5%, затем 10% |

| Находка кисточкой из подозрительного блока | 25 |

**Лесоруб** (`woodcutting`). Ветвь обсуждена. Опыт идёт только за топор и только по брёвнам, которые игрок не ставил сам. Брёвна выращенных деревьев считаются. За листву и посадку саженцев опыта нет. Бой топором относится к Воину.

| Действие | Опыт |
| --- | --- |
| Снятие коры с натурального бревна | 0,25 |
| Ножка огромного гриба | 0,5 |
| Бревно любого обычного дерева | 3,5 |
| Незерские стебли | 4,5 |

Уровень ветви даёт +0,2% скорости топора за уровень. Малые узлы всей ветви в сумме дают: скорость топора +15%, шанс не потратить прочность +20%, шанс лишнего бревна +12%, шанс лишнего саженца с листвы +25%.

| Большой узел | Эффект | Усилители за узлом (предложение) |
| --- | --- | --- |

Лесоповал никогда не ломает постройки. Он идёт только по брёвнам без отметки «поставлен игроком», соединённым с естественной листвой, и останавливается на поставленном бревне. Брёвна в постройках деревень не соединены с такой листвой и тоже не затрагиваются. Режим «без ограничения» сохраняет технический предел, чтобы одна вырубка не остановила сервер; его значение подбирается замером.

### Сектор «Ремесло»

**Строитель** (`building`). Ветвь обсуждена. Только строительные блоки: камень и его виды, кирпичи, доски, стекло, бетон, керамика, шерсть, плиты, ступени, заборы. Руды, земля, песок, факелы и семена не считаются. Блок, который игрок сломал там, где за последние сутки платили за постройку, отменяет оплату его следующего блока (с 2026-11-15).

## 3. Защита от накрутки

- **Поставленные блоки.** Сервер запоминает блоки, поставленные игроками. Их поломка не даёт опыта шахтёру, копателю и лесорубу. Поставленный песок и гравий падают и теряют отметку, поэтому для них действует счётчик: каждый поставленный блок отменяет опыт за следующий добытый блок того же вида.
- **Строитель.** Опыт только за позицию, где за последние 24 часа никто не ставил блок. Блок, сломанный там, где за последние 24 часа платили за постройку, отменяет оплату следующего блока того, кто сломал. Так цикл «поставить — сломать — поставить рядом» платит один раз (с 2026-11-15).
- **Наковальня.** Кузнецу платится только взятие, после которого прочность предмета выросла (с 2026-11-15).
- **Алхимик.** Платятся настоящие бутылки варки, и не больше одной варки за 20 секунд на игрока (с 2026-11-15).
- **Автоматизация поощряется.** Механизм, созданный игроком, приносит опыт своему владельцу. Например, умная вагонетка из будущего мода рубит дерево, а опыт лесоруба получает игрок, который её сделал. Для этого у мода будет общий интерфейс начисления опыта с указанием владельца. Автоматизация приносит 50% от опыта за ту же ручную работу и только пока владелец в игре. Механизм без владельца опыта не даёт.
- **Печь и другие станции.** Без автоматизации опыт получает тот, кто забрал результат.
- **Мобы из спавнера** дают 25% опыта. Способ определить такого моба нужно проверить прототипом.
- **Творческий режим и команды** опыта не дают.
- **Повторы.** Опыт за стрижку, дойку и разведение привязан к перезарядке животного. За получение урона не более 20 опыта в секунду.

Опыт за действия и списки предметов задаются в файле данных, сроки ограничений (сутки, 20 секунд, 20 опыта в секунду) — в коде.

## 4. Уровни

У игрока две шкалы опыта:

| Шкала | Сколько опыта | Куда тратятся очки |
| --- | --- | --- |
| Опыт ветви, своя у каждого направления | ×1 от полученного | только в своей ветви |
| Общий опыт, одна шкала на все направления | ×0,1–0,2 от полученного, для начала ×0,15 | в любую ветвь, например чтобы догнать отстающую |

Каждый уровень шкалы приносит одно очко этой шкалы. Опыт для следующего уровня растёт: `9 × уровень^1.5`, округление вниз. Цель: около 50 часов на полную ветвь при 75 уровнях. Это расчётная оценка, её нужно проверить замером в игре. С 2026-11-15 ветвь стоит больше, чем дают её 75 уровней (раздел 5): игрок выбирает. После 75-го уровня опыт ветви идёт в мастерство без очков (раздел 16). За опыт в игре выводится короткое сообщение над панелью предметов.

Смежное действие приносит опыт двум ветвям: основной ×1 и смежной ×0,8. Общая шкала считается только с основного начисления. Список хранится в файле данных:

| Действие | Основная ветвь | Смежная ветвь |
| --- | --- | --- |
| Руда сразу падает слитком (Переплавка) | Шахтёр | Кузнец, как за слиток из печи |
| Брёвна сразу падают досками (Плотник) | Лесоруб | Крафтер, как за крафт досок |
| Сбор незерского нароста | Фермер | Алхимик |
| Крафт инструмента или брони | Кузнец | Крафтер |
| Крафт еды | Повар | Крафтер |
| Убийство животного | Воин | Скотовод |
| Соединение книги и предмета на наковальне | Чародей | Кузнец |

Темп ветвей пересчитывается после обсуждения всех ветвей и проверяется замером в игре.

Уровень ветви даёт небольшую постоянную прибавку в своей сфере. Значимые эффекты находятся в дереве.

Очки можно перераспределить за обычный опыт Minecraft, цена должна быть невысокой.

**Экономика очков.** Решение владельца: 50 часов до 75-го уровня ветви, 75 уровней дают 75 очков, а узлы ветви стоят больше. Теперь ветвь стоит 79–85 очков, на 4–10 больше, чем дают её уровни (в среднем +10%). Своими очками ветвь не закрыть, игрок выбирает, что не брать, или доплачивает общими очками. Всё дерево стоит 1320 очков, а все 16 ветвей и общая шкала на 75-м уровне дают 1275: даже тот, кто прокачал всё, берёт не всё. Запас небольшой намеренно. По правилу «тугой цепочки» (Daniel Cook, «Value Chains», 2021) сток должен быть чуть больше источника, тогда каждое очко что-то значит, а игрок не упирается в стену.

**Правила для новых усилителей** (список с обоснованием в `examples/nodes/boosters.rs`):

- Только ключи эффектов, которые игра уже применяет и которые проверены в игре (раздел 9). Новых ключей нет, их по-прежнему 285.
- Новая ступень своего ключа не сильнее предыдущей и обычно слабее: Продление +25, +25, +25%, теперь +15%; Перегонка +20, +15, +15%, теперь +5%; Шипы +20, +20%, теперь +10% за ранг. Это убывающая отдача вместо роста силы.
- Если эффект большого узла упёрся в предел или это переключатель (Чистая вода, Экономия лазурита, Мягкое приземление, Огнестойкий, Возврат стрел), усилитель даёт ключ малого узла своей или соседней ветви, примерно как два малых узла. Это никогда не ключ-переключатель чужого большого узла, иначе усилитель раздавал бы его умение.
- Ни один усилитель не ускоряет опыт своей ветви: нет лишней рыбы и двойного улова (за них Рыбак получает опыт по числу рыб), двойни, быстрых печей и стоек, двойной порции Шефа, лишних слитков. Поэтому модель темпа из раздела 14 остаётся верной. Площадь работы (радиус Рудного нюха, Заливка, Чертёж, Подручные средства) тоже не росла: это нагрузка на сервер и клиент.
- Скорость передвижения есть только у Копателя (Лёгкая поступь), Стрелка (Стрельба на ходу) и Исследователя, чтобы она не стала общей прибавкой из любой ветви.

**Нумерация.** Новые узлы получили номера 995–1199 после всех старых, 995 прежних узлов сохранили номер, эффект и связи между собой. Каждый новый усилитель висит после последнего усилителя своей цепочки, поэтому за ним не стоит ни один старый узел. Сохранённые профили загружаются без потерь, `PROFILE_LAYOUT` не менялся. Это проверяют тесты `appended_nodes_keep_the_old_numbering` (контрольная сумма старых узлов дерева 0.4.11) и `a_profile_saved_with_every_old_node_keeps_them_all`. Генератор помечает новые узлы `added`, `examples/preview/preview.rs` нумерует их последними и не сливает в ранги со старыми.

**Раскладка.** Лучи ветвей остались как утверждены, длиннее стали цепочки усилителей. Боковые цепочки разложены заново, поэтому цветовые зоны окна изменились, и эталон `ZONE_CHECKSUM` в `lib.rs` пересчитан осознанно. `design/tools/check-tree.mjs`: пересечений связей, связей поверх узлов и наложений нет, ближайшие центры узлов в 33 единицах.

**Сводка для других модов.** В `pct:summary` у Воина, Стрелка и Стража выросло общее число рангов (второе число пары): 69 → 83, 68 → 83, 66 → 81. Мод, который делит рабочие ранги на общее число, увидит у прежних игроков меньшую долю, пока они не возьмут новые усилители.

## 7. Открытые решения

- Замер темпа прокачки людьми в игре. Цель остаётся прежней: около 50 часов до 75-го уровня ветви (владелец 2026-11-13 и 2026-11-15). С 2026-11-15 сервер сам пишет настоящий темп раз в час (раздел 14, «Счётчик настоящего темпа»). После недели игры на tidewill файлы `pace.jsonl` нужно собрать и сверить с моделью раздела 14.
- Решения по предложениям раздела 14 приняты 2026-11-15, что применено и что отклонено — в разделе 14, «Решения владельца 2026-11-15».
- Кузнец на золотой ферме. Владелец оставил золотое снаряжение в списке оплачиваемого. Средняя золотая ферма, около 1 000 слитков в час, переделанных в золотые лопаты, проходит ветвь примерно за 12 часов. Железная ферма — около 30 часов. Если 12 часов слишком быстро, золото можно убрать из списка: это одна строка в `examples/gen_tree.rs`. Решает владелец.
- Остаются фермы быстрее 15 часов, от которых владелец отказался защищаться: Страж 2,5 часа (кап 20 опыта в секунду не меняется), Чародей 9 часов (опыт по-прежнему за уровни), Фермер 12, Скотовод 13,5 и Повар 14 часов (лимита в час нет). Рыбак в увлечённой игре остаётся на 23 часах: его числа не меняли.

После ревью кода сохранение стало надёжнее, и это проверено в игре: опыт и отметки блоков записываются при немедленной остановке сервера, повреждённый профиль откладывается как `.bad`, запись идёт через временный файл, отметки ставятся только на блоки, дающие опыт.

Не проверено:

- Защита от повторного приветствия и остановка Жилы при поломке кирки: для них нужен специальный клиент или редкая ситуация, код проверен только ревью.
- Реальный темп прокачки. Бот ломает блоки медленнее человека, потому что команда ждёт подбор предметов. 50 часов на ветвь остаются расчётной оценкой.
- Несколько игроков одновременно с начислением опыта.

### Упрощения относительно разделов 2 и 5

Добыча:

- Износ при работе по площади снижается только за дополнительные блоки.
- Единственное улучшение износа у Лесоповала сразу даёт ×0,25.
- Улучшение Лёгкой поступи для снега приподнимает игрока.
- Боевая лопата даёт только урон.
- Предметы при радиусе подбора притягиваются постепенно.

Хозяйство:

- Сытная земля действует на любую фермерскую еду.
- Пугало отталкивает монстров от посевов.
- Вожак работает только при Shift. Статусы Верного пса действуют и в PvP.
- Быстрая плита ускоряет только еду, бонус берётся у последнего открывшего.
- Улучшение Едока на бегу даёт Скорость. Походная кухня объединяет супы. Секретный рецепт добавляет эффекты к существующим блюдам.
- Широкий разлив действует на внешнее кольцо. Смешению нужны разные зелья в одной варочной стойке.
- За двойню опыт рождения начисляется дважды.

Ремесло:

- Быстрый разбор помнит последние 4096 своих блоков.
- Инженер возвращает ингредиенты по одному. Ткач даёт шанс на +1. Вагонетки учитывают только удары того, кто держит предмет.
- Массовый крафт повторяет Shift-клик. Подручные заполняют сетку 3×3 после крафта, поровну на клетки.
- Бонусы печи берутся у последнего открывшего. Кольчужник действует на любую броню.
- Мастер за предел берёт 39 уровней. Обновление меняет предложения при открытии, раз в 5 минут.
- Книжник повышает стоимость. Перенос тратит исходный предмет. Точилка тратит книгу.

Странствия:

- Тяжёлая поступь даёт Скорость при двух и более тяжёлых частях брони.
- Возврат стрел кладёт их в инвентарь.
- Перезарядка живёт в памяти до перезапуска.
- Бонусы ближнего боя не действуют на Эндер-дракона.

В PvP вопреки общему правилу действуют атрибуты `max_health`, `movement_speed`, `step_height`, `luck`, а также Скорострел и скорость стрел. Владелец сервера принял это 2026-11-10.

Опыт за автоматизацию (раздел 3) приходит от модов с механизмами через консольную команду `pct-machine` (раздел 11). Обычные механизмы игры владельца не имеют и опыта не дают.

### Что проверено (2026-11-11)

Опыт проверен в игре на выделенном сервере, онлайн-режим: копание, рубка, созревший урожай, незерский нарост, строительство, крафт, печь, костёр, еда, варка, мёд, дойка, стрижка, разведение, приручение, наковальня, стол зачарования, торговля, кисточка, ближний бой, стрельба, урон от мобов, биомы, измерения, достижения, рыбалка.

Все 285 ключей эффектов проверены в игре на сборке `dev`. Каждый ключ включался отдельно через дерево в файле настроек, остальные эффекты и бонус уровня стояли на нуле, результат сравнивался с прогоном без узла. Узлы для двух игроков проверены с ботами на локальном сервере, который на это время работал без проверки аккаунтов. Рисуемое на экране (Рудный нюх, Орлиный глаз, окно дерева) проверено скриншотами. Также проверены: исключение боевых бонусов в PvP, кик клиента с другой версией протокола, опыт владельцу механизма онлайн и его отсутствие офлайн.

Ошибки, найденные и исправленные этой проверкой: Провокация не работала на сервере, контуры Рудного нюха скрывались камнем, Шеф терял вторую порцию из печи, Угощение не давало эффектов, Удар щитом не отталкивал моба, клиент не видел возвращённых семян, игроки в творческом режиме получали опыт за печь.

Оговорки:

- Морской клад работает на реальных узлах. При искусственно завышенной удаче (30 и больше) улов пропадает совсем, причина не найдена; узлами такая удача недостижима.
- Щит-стена проверена ударами через `/damage`, чтобы попасть внутрь задержки подъёма щита.
- Темп прокачки (около 50 часов на ветвь) рассчитан, но не измерен.

Известных лазеек не осталось. Блок, сдвинутый поршнем, с 0.4.10 уносит отметку «поставлен игроком» с собой (`mining.rs`, хук `piston_move`), а разрушенный поршнем блок её теряет. С 2026-11-15 отметку теряет и блок, разрушенный взрывом: HEAD на `explosion_hit_block`, где взрыв превращает каждый задетый блок в воздух, ставит блок в очередь, а тик сервера снимает отметку, как у поршня. Счётчик поставленного песка и гравия с 0.4.10 хранится в профиле игрока и переживает перезапуск сервера.

В одиночной игре процесс живёт дальше и может открыть другой мир. Поэтому с 2026-11-14 при остановке сервера мод сначала сохраняет всё, а потом забывает игроков, отметки поставленных блоков, коров, места построек, варочные стойки и чертежи прежнего мира. Фоновое чтение файла отметок, заказанное до остановки, отбрасывается. Раньше отметки и профили прежнего мира переносились в новый и могли сохраниться в его папку.

Часть событий движка срабатывает только при загруженном моде с типажом `Hooks`, поэтому мод ставит хуки прямо на функции разведения, наковальни и смерти, а приручение слушает через триггер достижения `tame_animal`. Опыт за наковальню с 2026-11-15 платится в `lan_station_combined`: там заканчивается взятие с наковальни у любого хоста, то есть на потоке сервера одиночной игры, у хоста LAN и на выделенном сервере. Раньше он платился в хуке `anvil_craft_post`, а тот срабатывает, только если движок отложил взятие ради модов. В одиночном мире опыта за наковальню не было. Теперь у каждого взятия одна точка оплаты, двойной оплаты нет.

Ещё с 2026-11-15:

- Чертёж каждого игрока хранится в папке мира, в файле `path_of_craft_tree/blueprints/<игрок>.json`, по именам блоков и их свойствам. Файл читается при первом использовании бумаги в этом мире и пишется при периодическом сохранении, при выходе игрока и при остановке сервера.
- Моб из спавнера получает тег `pct.spawner`. Тег сохраняется вместе с мобом в мире, поэтому после перезапуска такой моб по-прежнему даёт четверть опыта. Список номеров в файле не подошёл бы: после перезапуска у сущностей другие номера. Память по номеру осталась только для мобов, которые не хранят теги.
- Гарпун добивает моба, если урона хватает. Добивающий удар идёт через игру от имени игрока (`minecraft:generic_kill`, без учёта брони, как и обычный урон Гарпуна): моб умирает с добычей, убийство засчитывается игроку.
- Ландшафтник засыпает яму глубиной в блок землёй из инвентаря и делает на ней тропинку. Земля считается поставленной и опыта не даёт. Без земли тропинка, как раньше, опускается в яму.
- Знаток показывает варианты зачарования одной строкой над панелью быстрого доступа, а не в чате. Строка видна около трёх секунд и появляется заново при каждом новом наборе вариантов.

Дерево читается из файла только в сборке `dev`: `dev.ps1` задаёт при компиляции переменную `PCT_EXTERNAL_TREE`, потому что в профиле `dev` у лаунчера проверки отладки выключены. Сборки `performance` и `release` используют дерево, вшитое в мод.

## 10. Окно дерева (2026-11-11)

Дизайн утверждён владельцем по HTML-превью (`design/preview`) и перенесён в игру.

- **Раскладка.** Ветви разведены так, что поздние кольца не ложатся на соседние ветви и связи не пересекаются. Раскладку пишет `examples/gen_tree.rs`, проверяет `design/tools/check-tree.mjs`.
- **Ранги.** Два подряд идущих узла с одинаковым эффектом объединены в один узел с двумя рангами, таких узлов 83. В правом верхнем углу узла стоит отметка 0/2, 1/2 или 2/2. Клик добавляет один ранг, эффект растёт с рангом, следующий узел открывается только при полном ранге.
- **Сохранения.** Версия протокола поднята до 5. Старый профиль сохраняет опыт по всем ветвям, но изученные узлы сбрасываются.
- **Иконки.** У каждого узла своя пиксельная иконка 16×16 в стиле ванильного Minecraft. Исходники лежат в `design/icons/*.json`, правила стиля в `design/icons/STYLE.md`. Игра берёт их из атласа `data/atlas.png`, который собирает `design/tools/game-atlas.mjs`.
- **Цветовые зоны.** У каждой ветви свой цвет фона, вместе они образуют цветовой круг.
- **Частицы.** По изученным связям от центра к следующему узлу бегут частицы. На неизученных связях их нет.
- **Подписи веток.** Игровой шрифт шире, чем в превью. Ближние к центру подписи стоят на своих местах, а каждая следующая сдвигается от центра, пока не перестанет задевать уже поставленные.

Отличия от превью: игровой шрифт Minecraft вместо Tiny5, виньетка блоками по 16 пикселей, наведение на узел подсвечивается светлой заливкой.

### Поиск, планировщик и статистика (2026-11-15)

Под заголовком окна стоит строка инструментов в стиле кнопки сброса: поле поиска и каменные кнопки «Можно взять», «Планировщик», «Статистика». Включённая кнопка зеленеет. Сообщения окна появляются под этой строкой на 7 секунд.

- **Поиск.** У мод-экрана нет поля ввода, поэтому окно само принимает символы (screen_char_typed_pre) и клавиши (screen_key_pressed_pre). Ищется каждое слово запроса в названии узла, его описании и описаниях рангов, без учёта регистра, «ё» читается как «е». Найденные узлы рисуются поверх затемнённого дерева в жёлтой рамке, текущий в белой, в поле видно «3/12». Enter и стрелки ведут камеру к следующему узлу, ближние к центру идут первыми. Пока поиск идёт, клавиши-буквы не доходят до игры, поэтому клавиша инвентаря печатает букву, а не закрывает окно.
- **Можно взять.** Фильтр оставляет узлы, которые открыты и оплачиваются прямо сейчас, то есть с зелёной рамкой. Работает и вместе с поиском.
- **Планировщик.** Клик кладёт ранг в план вместо изучения. План рисуется голубыми рамками и голубым путём от изученного, на узлах стоит «+1» или «+2». Панель внизу слева показывает число рангов, разбивку по ветвям со своими очками, общие очки и сколько очков не хватает. Очки считаются в том же порядке, что и на сервере: сначала очки ветви, потом общие. «Применить» отправляет по порядку только оплачиваемые ранги, по 4 за кадр, обычными запросами llocate. Сервер проверяет каждый, как клик. Изученные ранги сами уходят из плана с новым профилем.
- **Строка сборки.** Это изученные ранги в допустимом порядке и план после них: PCT1: и base64url от номера нумерации узлов (PROFILE_LAYOUT), пар «узел, ранги» и контрольной суммы. Полное дерево ветерана занимает около двух символов на ранг. Строка попадает в буфер обмена игры. При загрузке ничего не принимается на веру: проверяются вид строки, версия, контрольная сумма, нумерация, каждый узел и число его рангов. Потом план подгоняется к своему профилю, окно сообщает, сколько рангов уже изучено и сколько не подошло.
- **Статистика.** Страница поверх дерева показывает время сессии, опыт по ветвям с уровнем и опытом в час, общую шкалу и пять лучших источников. Опыт за сессию клиент считает сам по приходящим профилям. Сессия начинается с первым профилем после входа на сервер.
- **Источники опыта.** О них знает только сервер, поэтому он раз в 5 секунд шлёт игроку суммы по парам «ветвь, источник» на своём канале path_of_craft_tree:gains (gains.rs). Источник — действие (ct:fish) или таблица добычи блока. Смежный опыт второй ветви в источники не попадает. Протокол не менялся: клиент без страницы канал не слушает, а с сервером без канала страница пишет, что источников нет.
- **Полоса опыта на экране.** По желанию, по умолчанию выключена. Наверху посередине показаны уровень ветви, которая получала опыт последней, и путь до следующего уровня в цвете ветви. Включается кнопкой на странице статистики или своей клавишей в «Настройки» → «Моды», по умолчанию без клавиши. Выбор хранится в config/path_of_craft_tree_client.txt.
- **Производительность.** Кадр окна читает только готовое: найденное хранится до нового запроса, фильтра или профиля, вид плана до нового плана или профиля, панели до изменения того, что они показывают. Индекс поиска строится при первом поиске. Бенчмарки enches/window.rs: поиск по запросу ~28 мкс, фильтр ~1,4 мкс, проверка совпадений всех узлов за кадр ~1 мкс, цена плана на ~700 рангов ~110 мкс (только при новом профиле), индекс ~1,8 мс один раз на дерево.

## 11. Опыт от машин других модов (2026-11-11)

Мод с механизмами (RustCraft) сообщает о действиях своих машин консольной командой `pct-machine <отчёт>` через `native_run_mod_command`. Без Path-of-craft-tree команда неизвестна и тихо не выполняется, поэтому моды не зависят друг от друга при сборке. Игрок, даже оператор, отправить отчёт не может: слушается только консольный путь.

| Отчёт | Что делает мод |
| --- | --- |
| `break <владелец> <измерение> <x> <y> <z> <блок> <инструмент>` | Поставленный блок теряет отметку и опыта не даёт; иначе владелец получает долю опыта за этот блок с этим инструментом |
| `place <измерение> <x> <y> <z> <блок>` | Блок, поставленный машиной, отмечается как поставленный игроком |
| `smelt <владелец> <предмет> <количество>` | Доля опыта за еду или слитки, как из своей печи |
| `craft <владелец> <рецепт> <предмет> <количество> <крафтов>` | Доля опыта за крафт, без награды за первый крафт |
| `kill <владелец> <id сущности> <тип моба>` | Доля опыта за убийство из лука, с урезанием за мобов из спавнера |
| `fish`, `milk`, `build`, `chunk`, `biome`, `structure` | Доля опыта Рыбака, Скотовода, Строителя и Исследователя по тем же правилам и с той же памятью, что у игрока |
| `repair`, `breed`, `shear`, `honey`, `brush`, `brew`, `enchant` с количеством | Доля опыта за поштучную работу в ветках Кузнеца, Скотовода, Копателя, Алхимика и Чародея |
| `slaughter <владелец> <id сущности> <тип животного>` | Доля смежного опыта Скотовода, как за убийство животного игроком; Воину и Стрелку ничего |
| `shot <игрок> <id сущности> <тип моба>` | Полный опыт Стрелка игроку, чьё оружие из мода с машинами убило моба |

С этими отчётами (добавлены 2026-11-11 по запросу RustCraft) машины могут качать все ветки, кроме приручения: оно остаётся за игроком. Форматы и правила — в `docs/machine-reports.md`.

Правила:

- Доля опыта машин — поле `machine_share` в `data/tree.json`, по умолчанию 0,5.
- Опыт получает только владелец, который на сервере.
- Эффекты дерева владельца на машины не действуют.
- Разбор отчётов лежит в `machine_rules.rs` и покрыт тестами, применение — в `machines.rs`.

Решения владельца (2026-11-11):

- Убийство турелью или стражем засчитывается ветке Стрелка.
- Опыт за слитки идёт за каждый слиток, в том числе за удвоенные дробилкой.
- Разрушитель блоков и бур-проходчик опыта не дают.
- Дневного потолка опыта от машин нет.

Форматы и правила для любых модов с машинами — в `docs/machine-reports.md`. Как машины RustCraft сопоставлены с отчётами — в его репозитории: `docs/design/path-of-craft-tree-contract.md`.

## 13. Вместе с другими модами сборки (2026-11-12)

В сборке сервера, кроме дерева, RustCraft, SoulsCraft и интерфейсные моды: JEI, карта мира, Mouse Tweaks, BetterF3. Всё собирается на одном коммите Horizon `7e4e421` и проверяется вместе на общем стенде `horizon-joint-dev`.

- **Клавиши.** Чутьё сокровищ перенесено с N на I: N у карты мира включает миникарту. Все семь клавиш дерева переназначаются в «Настройки» → «Моды» → кнопка «Настройки» рядом с Path-of-craft-tree (`keys.rs`). H и J по умолчанию совпадают с клавишами карты мира, каждый игрок разводит их сам.
- **Боевая сводка.** На каждом игроке лежит `pct:summary`: уровни и рабочие ранги Воина, Стрелка и Стража с их пределами. По ней SoulsCraft подстраивает силу мобов, владелец одобрил это 2026-11-12. Формат — в `docs/combat-summary.md`. С 2026-11-15 (после 0.4.11) в сводке ещё три поля: `all_levels` и `all_ranks` для всех 16 ветвей и `general` для общей шкалы. Прежние поля и их смысл не изменились, `v` осталось 1: по правилу формата добавленные поля версию не меняют, а читатель SoulsCraft незнакомые поля пропускает и отвергает только другое `v`. Так RustCraft и SoulsCraft смогут подстраиваться и под ремесло, и под добычу.
- **Опыт за усиленных мобов** (2026-11-13, v0.4.6). Метка `pct.xpNNN` на мобе умножает опыт за его убийство на NNN%, от 1 до 500. SoulsCraft ставит её усиленным мобам: ×(1 + 0,5·(hp_mult − 1)), гипотеза Г3 SoulsCraft, одобрена владельцем.
- **Мобы SoulsCraft в таблице здоровья** (2026-11-13, v0.4.9). Опыт за убийство считается от здоровья вида моба, для незнакомого вида — 20. Виды SoulsCraft внесены по её `data/mobs.json`, SoulsCraft присылает новые числа при изменениях (`docs/combat-summary.md`).
- **Посещённые чанки** (2026-11-13, v0.4.8). Компактный двоичный файл с дописыванием новых чанков вместо JSON, сохраняемого целиком. Замеры ботами — в разделе «Посещённые чанки» `docs/perf-log.md`.
- **Trait-мод SoulsCraft.** Если SoulsCraft станет trait-модом, охраняемые хуки Horizon начнут срабатывать. Проверено по коду 2026-11-13: дважды PCT ничего не заплатит, наковальня, разведение и убийства идут каждое одним путём.
- **Самотест.** Консольная команда `pct_selftest run` проверяет все отчёты машин и метку `pct.xpNNN` на настоящем мобе: 42 сценария (с 2026-11-15), эталон считается из `tree.json`. Семь из них (`team_…`) выводят в сеть сразу четырёх временных владельцев и проверяют, что опыт не перетекает от одного к другому, что общее состояние мира (место постройки на сутки, отдых коровы, метка поставленного блока) действует на всех, а долг за сломанный оплаченный блок ложится только на того, кто сломал, а посещённые чанки и разовые находки у каждого свои, и что повышение уровня одного не трогает профили других. Её запускает `joint.ps1 check` стенда. Последний общий раунд 2026-11-14 22:11 прошёл с 0.4.11: PCT 31/31, RustCraft 80/80, SoulsCraft 58/58. `pct_selftest summary` печатает сводку игроков. Пять сценариев проверяют настройки сервера, команды администратора, новые поля сводки и долю группы (раздел «Сервер для владельца» ниже). Самотест всегда идёт с настройками по умолчанию, поэтому множители владельца на эталон не влияют.
- **Сервер для владельца** (2026-11-15, пункты 13, 14, 16 и 18 раздела 15).
  - Настройки без пересборки лежат в `config/path_of_craft_tree-server.json` папки сервера: общий множитель опыта, множители ветвей, замена `general_share` и числа групповой игры. Выбрана папка `config`, а не папка мира: файл доступен до открытия мира, лежит там, где владелец правит остальные настройки, и не уезжает с копией мира на другой сервер. Формат JSON, как у `tree.json`. Нет файла — он создаётся со значениями по умолчанию, и они дают ровно прежнее поведение. Неверное значение остаётся по умолчанию с предупреждением в журнале, а сервер не падает. Перечитывается командой `/pct admin reload`. Множители входят в дерево сервера (`Tree::scale`) и действуют во всех путях начисления: ручном, смежном, от машин и на долю группы. Общая шкала получает долю от умноженного опыта. Разбор и проверки — в `settings_rules.rs`, чтение файла — в `settings.rs`.
  - Команды администратора `/pct admin give|take|level|reset|show|reload` доступны операторам уровня 2, как ванильная `/experience`, и консоли. Horizon передаёт уровень оператора в `NativeServerPlayer::permission` хука `perform_command`, клиенту ветка `admin` видна только при этом уровне. Игрок в сети задаётся по имени или UUID, игрок не в сети — по UUID, тогда меняется его файл. Опыт выдаётся точно, без множителей. Узлы, на которые после снятия опыта не хватает очков, возвращаются. Каждое изменение пишется в журнал, игрок получает сообщение в чат. Код — `command_rules.rs` и `commands.rs`.
  - Таблица лидеров для сайта: `/pct leaderboard on|off`, по умолчанию выключено. В `<мир>/path_of_craft_tree/leaderboard.json` попадают только согласившиеся игроки: имя, UUID, уровни 16 ветвей, их сумма, уровень общей шкалы и время. Файл переписывается сразу при `on` и `off` и на периодическом сохранении, если уровни изменились. Формат для сессии сайта — `docs/leaderboard.md`.
  - Групповая игра: `/pct group invite <игрок>`, `accept`, `leave`, `list`. Товарищ по группе в 32 блоках от получившего опыт, в том же измерении, в выживании или приключении, получает 15% основного опыта в ту же ветвь. Это добавка: у получившего опыт ничего не отнимается. Доля платится один раз за начисление и не передаётся дальше. В группе до 4 игроков, приглашение живёт 2 минуты, группы хранятся только в памяти и распадаются при выходе игрока. Доля, радиус и размер группы задаются в настройках сервера. Временные владельцы самотеста к настоящим игрокам в группу не попадают. Положение игроков берётся из списка сервера раз в 10 тиков: внутри хода игрока список сервера недоступен. Код — `group_rules.rs` и `groups.rs`, доля начисляется в `glue::grant`.
- **Записи LetsCam.** При просмотре записи сообщения мода приходят клиенту снова. Обработчики только обновляют состояние клиента, поэтому это безопасно. После просмотра окно дерева показывает профиль из записи до следующего сообщения сервера.
- **Сборка клиента.** Лаунчер сначала собирает клиента на базовом коммите окружения (Nightly `fdc87ae`), где дерево не собирается, и только потом на `7e4e421`. Флага, который это отключает, нет. Лишний заход уйдёт, когда выйдет Nightly не старше `7e4e421`.

## 14. Темп прокачки (2026-11-14)

Проверка цели «около 50 часов на ветвь» расчётом, без игры. Программа `examples/pace.rs` (`cargo run --example pace`) берёт опыт за действия, кривую уровней и доли из `data/tree.json` и для каждой ветви задаёт модель часа игры: сколько раз в час игрок делает каждое действие. Темп считается без эффектов дерева и без бонуса уровня. Замер людьми в игре он не заменяет: модели ниже — гипотезы, их стоит сверить с первыми игроками.

### Сколько опыта нужно

Уровень 75 стоит 178 264 опыта ветви (`9 × уровень^1,5`, округление вниз, сумма по уровням 1–75). На 50 часов это 3 565 опыта в час. До 2026-11-15 узлы одной ветви стоили от 63 до 73 очков и покупались своими очками раньше 75-го уровня: на уровне 63 это 115 637 опыта, на уровне 73 это 166 690. Столбец «Часы до всех узлов» ниже посчитан для того дерева. Теперь ветвь стоит 79–85 очков (раздел 5), своими очками её не закрыть, и `pace` показывает в этом столбце часы до 75-го уровня.

### Результат

Два режима на ветвь:

- **Увлечённая игра** — игрок весь час занимается этим делом с обычной для середины игры подготовкой: алмазный инструмент, зачарованная удочка, поле, загон.
- **Ферма** — самый быстрый повторяемый цикл, который допускают текущие правила мода. Это не баги игры, а то, что игроки найдут.

«Флаг»: быстрее 30 часов или медленнее 80 часов в увлечённой игре.

### Из чего взяты числа

Из механики игры (код 1.21, на который опирается мод):

- Время ломания: урон за тик = скорость инструмента / твёрдость / 30; скорость: железо 6, алмаз 8, незерит 9, Эффективность прибавляет n² + 1, Спешка 20% за уровень. После блока, который ломался дольше тика, игра ждёт 5 тиков.
- Руда на Y=−58: параметры генерации руды 1.21 (сколько попыток на чанк, распределение по высоте, размер жилы). Выходит алмаз примерно на 350 блоков породы, редстоун на 170. Допущения: жила размера n даёт около 0,75 n блоков, в ветвевой шахте игрок видит и забирает руду в стенах, это ×2 к руде на добытый блок.
- Рыбалка: ожидание 100–600 тиков минус 100 за уровень Приманки, затем 20–80 тиков подплывает рыба; доли рыбы, мусора и сокровищ по весам 85/10/5 со сдвигом −1/−2/+2 за уровень Везучего рыбака.
- Рост культур: случайный тик блока раз в 68 с; стадия растёт с шансом 1/(⌊25/f⌋+1), f = 10 на влажной пашне, 5 в сплошном блоке одной культуры. Пшеница в сплошном поле созревает за 48 минут, рядами за 24. Арбуз и тростник по тем же случайным тикам.
- Перезарядка разведения 5 минут, варка 20 секунд, коптильня 5 секунд, стоимость уровней опыта Minecraft (2L+7, 5L−38, 9L−158).
- Здоровье мобов — таблица `mob_health` из `tree.json`, средний ночной монстр 19,6 по весам появления в верхнем мире.
- Правила мода: дойка раз в 5 минут с коровы, до 2026-11-15 всегда 3 бутылки за варку (теперь настоящие бутылки и не чаще раза в 20 секунд), кап 20 опыта в секунду у Стража, ×1,5 за выстрел с 30 блоков, ×0,8 за смежный опыт.

Допущения, их надо проверить игрой: доля часа на само действие (шахта 40%, лопата 50%), 8 брёвен на дерево и 30 секунд на подход, частота монстров (150 и 120 в час), урон по Стражу, 1 500 блоков в час у строителя, размер поля и загона, объём крафта, 3 000 очков опыта Minecraft в час у чародея, 150 медных и 60 железных руд в час у кузнеца, скорость лошади 9,5 м/с и 60% новых чанков, число биомов (64), видов структур (34) и достижений (60 из 122) за ветвь.

### Ветви вне коридора

- **Рыбак, 23 часа.** Удочка с Приманкой III ловит раз в 9–10 секунд, это около 360 уловов и 7 600 опыта в час. Удочка без чар ловит в 2,4 раза реже: около 66 часов. Ловить можно с автокликером, ограничений на AFK у ветви нет, поэтому 21 час ветвь прокачивается без игрока.
- **Лесоруб, 103 часа.** Дерево ломается быстро, время уходит на подход, столбы и листву: около 870 брёвен в час. Лесоповал в дереве ускорит ветвь в разы, модель его не учитывает.
- **Исследователь, 102 часа.** Разовые источники — биомы, структуры, достижения, измерения — дают не больше 20 300 опыта, это уровень 31 из 75. Остальное — новые чанки, около 130 000 при текущей цене и торговле в модели, до 160 000 без неё, то есть мир до 6 400 × 6 400 блоков на одного игрока: заметный рост мира и файла посещённых чанков. На элитрах 33 часа. Зал торговли без лимитов: при скидке вылеченных жителей сотни сделок в час, около 600 сделок в час — около 30 часов.
- **Крафтер, 86 часов.** Крафт сам по себе мгновенный, темп задаёт добыча сырья: лучший рецепт — 8 ингредиентов за 4 опыта (печь, сундук). Разовые первые крафты дают около 6 000 опыта.
- **Повар, 31 час, на границе.** Опыт зависит только от подачи еды: картофель с поля даёт 1,7 картофелины за сбор и 4 опыта за каждую из коптильни, то есть больше, чем сам сбор даёт Фермеру. С большим полем ветвь проходится за 10 часов.

Фермы, которые пробивают ветвь быстрее 15 часов:

- **Страж, 2,5 часа.** Зомби в ловушке бьёт в поднятый щит: 3 урона × 6 опыта = 18 опыта в секунду, кап 20 в секунду не мешает. Это 72 000 в час, полуAFK.
- **Кузнец, 4 часа.** Опыт «за инструмент или броню» даёт любой предмет на `_shovel`, `_sword` и так далее, в том числе деревянная лопата: одно бревно — две лопаты — 30 опыта. Ещё не учтено: починка на наковальне засчитывается за любое взятие с наковальни без книги, то есть и за переименование за 1 уровень.
- **Алхимик, 9 часов.** Четыре стойки, по одной незерской бородавке на варку; правило всегда платит за 3 бутылки.
- **Чародей, 9 часов.** Опыт идёт за списанные уровни, а уровни на 1–3 стоят 7–11 очков опыта Minecraft против 100 с лишним на 30-м. Те же очки, потраченные по одному уровню в слоте 1, дают в 11 раз больше опыта.
- **Повар 10, Фермер 12, Скотовод 13 часов.** Опыт растёт вместе с размером поля и загона, а они строятся за пару часов.

Стрелок и Воин на башне-ферме мобов (обычное появление, не спавнер) — 18 часов, Строитель на цикле «поставить — сломать — поставить рядом» — 19,5 часа.

### Общая шкала

Общая шкала получает 15% основного опыта всех ветвей, смежный опыт в неё не идёт.

- Одна ветвь до 75-го уровня даёт общей шкале 26 740 опыта, это 34-й уровень.
- При смешанной игре, когда час делится поровну между шестнадцатью ветвями, общая шкала растёт в 2,4 раза быстрее средней ветви: через 50 часов ветви на уровнях 18–33, общая шкала на 33-м; через 100 часов — 24–44 и 44; через 200 — 32–58 и 59. Все 75 общих очков приходят через 356 часов, когда ни одна ветвь ещё не дошла до максимума. Все ветви при равной доле времени доходят до 75 через 1 644 часа: последним упирается самый медленный Лесоруб.
- Если идти ветвь за ветвью, общая шкала заполняется задолго до конца: к 977-му часу в ней набирается 419 000 опыта при нужных 178 264.

Вывод: общая шкала — это примерно ещё одна ветвь очков (75), которая приходит к середине пути, как и задумано для «догнать отстающую». Если нужно, чтобы она росла наравне со средней ветвью при смешанной игре, `general_share` надо снизить с 0,15 до 0,06.

### Эффекты, которые модель не учитывает

Бонус уровня (+0,2% за уровень, до +15% скорости инструмента) и узлы дерева ускоряют вторую половину ветви: Забой (3×3) и Жила у Шахтёра, Экскаватор и Обрушение у Копателя, Лесоповал у Лесоруба, Жнец и Зелёные пальцы у Фермера, Быстрый клёв у Рыбака, Быстрая варка, Быстрая плита и Плавильщик там, где упор в станции. У собирательских ветвей с узлами площади реальное время будет заметно меньше таблицы: Забой ломает до 9 блоков за раз. Тем, где упор в подачу сырья (Повар, Кузнец, Крафтер), ускорение станций почти не помогает.

Изменения правил в коде (данными не решаются):

1. **Страж.** Кап 20 опыта в секунду (`MAX_HIT_XP_PER_WINDOW` в `actions.rs` и `BLOCK_XP_PER_SECOND` в `fx_roam_rules.rs`) заменить на окно подлиннее, например 600 опыта за 5 минут. Увлечённая игра (около 375 опыта за 5 минут) его не заметит, ловушка упрётся в 7 200 в час, это 25 часов.
2. **Чародей.** Платить за очки опыта Minecraft, а не за уровни, например 1 опыт ветви за очко. Стол на 30-м уровне и по одному уровню тогда дают одинаково, увлечённая игра около 49 часов.
3. **Кузнец.** Опыт за наковальню давать, только если прочность предмета выросла, а не за любое взятие без книги.
4. **Алхимик.** Считать реальное число бутылок вместо постоянных трёх, и не больше одной варки за 20 секунд на игрока. Ферма из четырёх стоек тогда упрётся в одну стойку: около 27 часов.
5. **Строитель.** Не платить за блок, который тот же игрок сломал в течение 24 часов, или забирать опыт при такой поломке. Иначе цикл «поставить — сломать — поставить рядом» остаётся.
6. **Масштабируемые ветви: Фермер, Скотовод, Повар, Воин, Стрелок.** Их опыт растёт с размером фермы. Самый простой общий ограничитель — не больше 7 000 опыта ветви в час по скользящему окну (вдвое больше цели). Это нижняя граница около 25 часов на ветвь для любой фермы, увлечённую игру он не задевает. Ограничитель нужно сделать в коде, число можно хранить в `tree.json`.

### Решения владельца 2026-11-15

Цель прежняя: около 50 часов до 75-го уровня ветви. Доля общей шкалы остаётся 0,15.

Применено в данных:

| Ветвь | Что | Было → стало |
| --- | --- | --- |
| Лесоруб | брёвна, незерские стебли | 2, 2,5 → 3,5, 4,5 |
| Исследователь | `act:chunk`, `act:trade` | 1, 10 → 2, 3 |
| Крафтер | `act:craft` за ингредиент | 0,5 → 0,8 |
| Повар | `act:cook` | 4 → 3 |
| Строитель | `act:build`, `act:deco` | 1,5, 2 → 2, 2,5 |
| Кузнец | `gear_suffixes` | любые `_sword`, `_shovel`… → только железо, золото, медь, кольчуга, алмаз, незерит |

Применено в коде:

- **Наковальня.** Взятие без книги платит Кузнецу, только если тот же предмет вышел с меньшим износом, то есть ушёл с наковальни починенным. Переименование и соединение целых предметов ничего не дают (`limits::is_anvil_repair`).
- **Алхимик.** Хук завершения варки читает стойку и платит за заполненные бутылки, от одной до трёх. Игроку оплачивается не больше одной варки за 20 секунд (`limits::BrewPace`), лишние стойки опыта не прибавляют. Отчёт машины `brew` получил необязательное число бутылок (`docs/machine-reports.md`). Машинам темп варки не ограничен: каждая их стойка настоящая, как и печь.
- **Строитель.** Позиция без оплаты на сутки осталась. Кроме неё: блок, сломанный на позиции, где за последние сутки платили за постройку, даёт тому, кто сломал, долг. Следующий его блок, за который полагалась бы оплата, ничего не платит и гасит долг (`limits::RebuildDebts`). Долг живёт сутки. Без этого цикл «поставить — сломать — поставить рядом» платил за каждое новое место. Правило по одной позиции («не платить там, где игрок сломал») цикл не закрывает: соседняя клетка всегда новая. Долги общие для игрока и его машин и переживают перезаход, но не перезапуск сервера, как и память позиций.

Отклонено: числа Рыбака, окно для Стража (кап 20 опыта в секунду остаётся), опыт Чародея за очки (остаётся за уровни), лимит в час для Фермера, Скотовода, Повара, Воина и Стрелка.

- **Строитель.** Ферма «поставить — сломать — поставить рядом» закрыта. Самое быстрое, что осталось, — ставить на новые места свежий булыжник из генератора: половина времени уходит на добычу. Это 25 часов, и это уже почти настоящая постройка.
- **Исследователь.** Зал торговли при 600 сделках в час теперь даёт 1 800 опыта в час, около 90 часов вместо 30.
- **Смешанная игра.** Через 50 часов ветви на уровнях 20–33, общая шкала на 34-м; через 100 часов — 27–44 и 46; через 200 — 36–58 и 60. Все 75 общих очков приходят через 336 часов, все ветви доходят до 75 через 1 193 часа (было 1 644).

### Счётчик настоящего темпа

С 2026-11-15 сервер сам считает, как быстро качаются настоящие игроки, чтобы модель выше можно было сверить с игрой.

- Раз в час (`pace_log::INTERVAL`) сервер пишет в журнал по строке на каждого игрока, который играл в этот час: `pace a1b2c3d4: 57 min, mining 4613, smithing 210; general 692`. Те же данные дописываются JSON-строкой в `<мир>/path_of_craft_tree/pace.jsonl`: `{"at":…,"interval_s":3600,"player":"a1b2c3d4","minutes":57.0,"general":692.0,"xp":{"mining":4613.0,"smithing":210.0}}`.
- Опыт ветви считается вместе со смежным: это прирост таблицы опыта профиля при каждом начислении. `general` — прирост общей шкалы. Минуты — время в режиме выживания или приключения по настоящим часам, отсчёт раз в секунду.
- Личных данных нет. Игрок назван 8 шестнадцатеричными цифрами хеша от UUID с солью мира. Соль — 16 случайных байт в `<мир>/path_of_craft_tree/pace_salt.txt`, создаётся при первой записи. Имя и UUID не пишутся, без файла соли хеш с UUID не сопоставить. В пределах мира хеш игрока не меняется, поэтому часы одного игрока можно сложить.
- Не считаются: время в творческом режиме и режиме наблюдателя, временные владельцы самотеста. Игрок без минут игры в строку не попадает, даже если его машины принесли опыт.
- Час, в котором игрок вышел, тоже пишется, с его неполными минутами. При остановке сервера неполный час дописывается с настоящей длиной в `interval_s`. Счётчик живёт в памяти: при падении сервера неполный час теряется.
- Консольная команда `pct_pace` печатает текущий час для каждого хеша и через сколько минут он будет записан. Она для проверки.

## 16. Мастерство после 75 (2026-11-15)

Пункт 17 раздела 15. После 75-го уровня опыт ветви не пропадает: он и раньше копился в профиле. Теперь он идёт в мастерство — медленную шкалу из 10 рангов. Мастерство не даёт очков и эффектов, только ранг и титул. Это награда за любимое дело, а не сила, поэтому оно не ломает баланс дерева и сводку для SoulsCraft. Так устроена мета-прогрессия в Hades: косметика и история вместо силы, чтобы прогресс не подменял мастерство игрока (Josh Ge, «Designing for Mastery in Roguelikes», 2025).

Ранг r стоит `floor(6000 × r^1,25)` опыта ветви сверх 178 264 опыта 75-го уровня. Каждый ранг немного дольше предыдущего (Ian Schreiber, «Game Balance Concepts», Level 7: интервал между уровнями слегка удлиняется). Первый ранг приходит быстро, чтобы игрок узнал о шкале, десятый — редкость.

Игрок показывает один титул. По умолчанию это титул ветви с самым высоким рангом мастерства, при равных рангах — с большим опытом. Можно выбрать ветвь самому, если у неё есть ранг мастерства.

### Данные и код

- `data/tree.json`: поле `mastery` (`curve` — та же форма, что у кривой уровней, `max_level` — число рангов; `titles` — титулы рангов 1–9) и `legend` у каждой ветви — титул десятого ранга. Дерево без `mastery` мастерства не имеет. Числа живут в `examples/nodes/mastery.rs`.
- `rules.rs`: `mastery_progress(xp)` — ранг и доля следующего, `mastery_rank(profile, branch)` — ранг ветви, `max_mastery()`, `mastery_title(branch, rank)`, `shown_title(profile)` — показанный титул (`Title { branch, rank, text }`), `choose_title(profile, branch)` — выбор, `None` возвращает автоматический.
- Профиль: поле `title` — ветвь выбранного титула, по умолчанию пустое и в файл не пишется. Старые профили загружаются как есть. Сброс дерева титул не трогает. Поле уходит клиенту в сообщении о профиле (`for_client`).
- Сервер (`glue.rs`): канал `path_of_craft_tree:title`, в нём id ветви в UTF-8 или пустое сообщение для автоматического титула. Ветвь без ранга мастерства сервер отклоняет. Клиент отправляет запрос, если окно положит его в `client().title_request` (`Some("mining")` или `Some(String::new())`). Версия протокола не менялась: старый клиент этот канал просто не использует.
- Строка над панелью предметов после 75-го уровня показывает ранг и титул: «+12.0 опыта · Шахтёр 75 · мастерство 3: Мастер». Новый ранг мастерства, как и новый уровень, показывается сразу и сохраняет профиль.

### Для окна дерева

Окно пока ничего не показывает. Предлагается: у эмблемы ветви — ранг мастерства звёздами или числом и полоса до следующего ранга (`mastery_progress`), в подсказке ветви — титул, в углу окна — показанный титул (`shown_title`) с выбором ветви. Префикс в чате не сделан: его стоит добавлять, только если в Horizon есть штатный способ оформить имя игрока в чате; в этом срезе это не проверялось, а подменять сообщения чата нельзя.

Тесты: 8 в `rules.rs` (кривая, титулы, выбор, сохранение, клиент, старый профиль, сломанная кривая) и `the_shipped_mastery_is_slow_capped_and_titled_per_branch` в `lib.rs`.

## 17. Английский язык (2026-11-15)

Пункт 12 раздела 15. Тексты мода пишутся по-русски, а игрок, у которого игра не на русском, видит их по-английски. Язык берётся из настроек игры: у клиента — свой (`settings.language`), у сервера — язык каждого игрока, который его клиент сообщил (`native_player_client`). Русский остаётся для кодов `ru_*` и для неизвестного языка, английский — для всех остальных.

- Словарь — три файла данных мода: `data/en-names.json` (ветви, титулы, названия узлов и их части), `data/en-texts.json` (описания узлов и рангов), `data/en-ui.json` (окно, сообщения, команды). Ключ — русский текст, значение — английский.
- Название узла `Основа: уточнение` переводится по частям, число или ранг в уточнении остаётся как есть. Текст с числами или латинскими словами (имя игрока, id блока) ищется по шаблону, где они заменены на `{}`, и подставляется обратно.
- Клиент переводит дерево один раз, когда оно приходит с сервера, поэтому окно, подсказки и поиск работают уже с английскими текстами. Панели окна переводятся, когда строятся, а не каждый кадр.
- Сервер переводит строку опыта над панелью, отказ в сбросе, сообщение о версии мода, ответы `/pct` и сообщения группы. Консоль сервера остаётся на русском.
- Текста, которого нет в словаре, игрок увидит по-русски, ничего не ломается. Тест обвязки проверяет, что у каждого текста дерева есть перевод, поэтому новый узел без перевода не пройдёт `cargo test`.
- Не переведено: выводы команд администратора с названиями ветвей внутри и журнал сервера. Описание Карманного верстака в русском содержит заметку «Проверить плейтестом, не слишком ли сильно» (из таблицы раздела 2); в английском её нет, русский текст стоит поправить вместе с таблицей.
