# Path-of-craft-tree: дизайн мода

Дата: 2026-11-10, обновлено 2026-11-11. Статус: все шестнадцать ветвей обсуждены и реализованы, дерево проверено в игре (раздел 9). Разделы 2–5 описывают замысел. Где реализация от него отходит, это записано в разделах 9–11.

## 1. Идея

Игрок получает опыт в направлении за то, что им занимается: кирка качает шахтёра, лопата копателя. Уровень направления немного усиливает персонажа в этой сфере и приносит очки для огромного дерева пассивных умений в духе Path of Exile.

Мод состоит из клиентской и серверной половин и вырос из прототипа окна дерева на 13 узлах. Сервер принимает все решения, клиент только показывает дерево и отправляет запросы. Игрока без нужной версии мода сервер отключает.

Технический идентификатор мода: `path_of_craft_tree`. Название для игроков: Path-of-craft-tree.

## 2. Направления

Шестнадцать направлений в четырёх секторах дерева. Значения опыта указаны для первого баланса и живут в файле данных, поэтому меняются без пересборки.

### Сектор «Добыча»

**Шахтёр** (`mining`). Ветвь обсуждена. Опыт идёт только за кирку, только по блокам, которые игрок не ставил сам, и только если блок действительно выпадает. Шёлковое касание и удача на опыт не влияют.

| Блок | Опыт |
| --- | --- |
| Незерак | 0,25 |
| Камень, андезит, диорит, гранит, туф, базальт, чернокамень, эндерняк | 0,5 |
| Глубинный сланец | 1 |
| Незерская золотая руда | 3 |
| Медь, незерский кварц | 4 |
| Уголь | 5 |
| Железо, редстоун | 8 |
| Лазурит | 12 |
| Обсидиан, золото | 15 |
| Алмаз | 50 |
| Изумруд | 60 |
| Древние обломки | 150 |

Уровень ветви даёт +0,2% скорости кирки за уровень. Малые узлы всей ветви в сумме дают: скорость кирки +15%, шанс не потратить прочность +20%, шанс лишней руды +12%, опыт Minecraft с руды +30%.

| Большой узел | Эффект | Усилители за узлом (предложение) |
| --- | --- | --- |
| Жила | Руда ломается цепочкой до 8 блоков, прочность тратится за каждый | Прочность за блок ×0,75, ×0,5, ×0,25; цепочка до 12, затем до 16 |
| Забой | Переключаемый режим копания 3×3, прочность ×2 | Прочность ×1,5, затем ×1,2 |
| Рудный нюх | Подсветка руды в радиусе 6 блоков на 10 секунд, с перезарядкой | Радиус 8, затем 10; перезарядка короче |
| Переплавка | Железо, медь и золото падают сразу слитками | Шанс лишнего слитка 5%, затем 10% |
| Магнитная кирка | Добыча сразу попадает в инвентарь | Опыт Minecraft тоже зачисляется сразу |
| Прилив сил | После добычи руды 8 секунд ускоренной добычи (Спешка I) | Длительность 12 секунд; Спешка II; дополнительно Скорость I |
| Жадность | 10% шанс лишнего алмаза или изумруда | 15%, затем 20% |
| Твёрдая рука | Обсидиан и обломки добываются вдвое быстрее | Втрое быстрее; действует и на глубинный сланец |
| Глаза крота | Ночное зрение ниже уровня Y=0 | Порог Y=40; действует под водой |
| Закалка шахтёра | Меньше урона от падения и лавы под землёй, 25% | 40%, затем 50% |

**Копатель** (`digging`). Ветвь обсуждена. Опыт идёт за лопату по блокам, которые игрок не ставил сам, и за раскопки кисточкой.

| Действие | Опыт |
| --- | --- |
| Снежный слой | 0,1 |
| Блок снега | 0,2 |
| Земля, трава, песок, красный песок | 0,4 |
| Гравий, ил | 0,5 |
| Подзол, мицелий, песок душ, почва душ | 0,75 |
| Глина | 1 |
| Тропинка лопатой (первый раз на блоке) | 0,4 |
| Находка кисточкой из подозрительного блока | 25 |

Уровень ветви даёт +0,2% скорости лопаты за уровень. Малые узлы всей ветви в сумме дают: скорость лопаты +15%, шанс не потратить прочность +20%, шанс лишней добычи с песка, гравия и глины +15%.

| Большой узел | Эффект | Усилители за узлом (предложение) |
| --- | --- | --- |
| Экскаватор | Переключаемый режим копания 3×3, прочность ×2 | Прочность ×1,5, затем ×1,2; режим 5×5 |
| Обрушение | Столб песка или гравия над блоком ломается целиком, до 8 блоков | Меньше расход прочности; до 16 блоков |
| Кладоискатель | 1% шанс находки в земле. Обычно мелочь: кость, кремень, самородки. Ценное, например изумруд, примерно одна находка из 50 | 2%, затем 3%; более редкие находки |
| Археолог | Кисточка работает вдвое быстрее | Шанс лишней находки 10%, затем 20% |
| Кремнёвый глаз | Гравий всегда даёт кремень | Шанс двух кремней 25% |
| Стекольщик | Песок падает сразу стеклом, режим переключается | Шанс лишнего стекла 10%, затем 20% |
| Засыпка | Лопата заполняет яму 3×3 землёй или песком из инвентаря | Область 5×5; шанс не потратить блок |
| Ландшафтник | Лопата делает тропинку сразу 3×3 | 5×5; выравнивание неровностей |
| Лёгкая поступь | Нет замедления на песке душ, иле и снегу | Рыхлый снег не затягивает |
| Боевая лопата | Лопата бьёт как меч того же материала | Шанс оглушить или отбросить врага |

**Лесоруб** (`woodcutting`). Ветвь обсуждена. Опыт идёт только за топор и только по брёвнам, которые игрок не ставил сам. Брёвна выращенных деревьев считаются. За листву и посадку саженцев опыта нет. Бой топором относится к Воину.

| Действие | Опыт |
| --- | --- |
| Снятие коры с натурального бревна | 0,25 |
| Ножка огромного гриба | 0,5 |
| Бревно любого обычного дерева | 2 |
| Незерские стебли | 2,5 |

Уровень ветви даёт +0,2% скорости топора за уровень. Малые узлы всей ветви в сумме дают: скорость топора +15%, шанс не потратить прочность +20%, шанс лишнего бревна +12%, шанс лишнего саженца с листвы +25%.

| Большой узел | Эффект | Усилители за узлом (предложение) |
| --- | --- | --- |
| Лесоповал | Дерево падает целиком, до 32 брёвен, прочность тратится за каждое | Прочность ×0,75, ×0,5, ×0,25; до 64 брёвен; последний усилитель снимает ограничение: любое дерево целиком |
| Лесничий | На месте срубленного дерева сам сажается саженец | Шанс, что он сразу подрастёт; посадка 2×2 для больших деревьев |
| Щедрая крона | При вырубке листва осыпается сразу | Чаще яблоки и палки; шанс золотого яблока |
| Штабель | Добыча с Лесоповала собирается в одном месте у игрока | Сразу в инвентарь |
| Чистильщик | Один клик снимает кору со всего ствола | Шанс лишней коры или опыта |
| Плотник | Брёвна падают сразу досками, режим переключается | 5 досок вместо 4; шанс палок |
| Углежог | 10% шанс, что бревно упадёт древесным углём | 20%, затем 30% |
| Живица | Каждые 8 брёвен топор чинится на единицу прочности | Каждые 5, затем каждые 3 |
| Лесной страж | В лесных биомах: скорость передвижения и медленная регенерация | Сильнее; действует и на незерские леса |
| Дары леса | Редкая находка в вырубке: мёд, гнездо, яблоко | Чаще; более ценные находки |

Лесоповал никогда не ломает постройки. Он идёт только по брёвнам без отметки «поставлен игроком», соединённым с естественной листвой, и останавливается на поставленном бревне. Брёвна в постройках деревень не соединены с такой листвой и тоже не затрагиваются. Режим «без ограничения» сохраняет технический предел, чтобы одна вырубка не остановила сервер; его значение подбирается замером.

**Рыбак** (`fishing`). Ветвь обсуждена. Опыт идёт за улов удочкой, который игрок подобрал. Рыба, сокровище и мусор оплачиваются по-разному: сокровище дороже всего.

| --- | --- |
| Мусор | 6 |
| Рыба | 18 |
| Сокровище | 50 |

| Быстрый клёв | Рыба клюёт быстрее | Сильнее |
| Двойной улов | 15% шанс второй добычи | 25%, затем 35% |
| Чистая вода | Меньше мусора | Мусора нет совсем |
| Дар глубин | Редкий улов: книги, слитки | Ценнее |
| Морская поступь | Быстрое плавание | Дольше под водой |
| Сырое не страшно | Сырая рыба насыщает как жареная | Даёт короткий бонус |
| Гарпун | Удочка сильнее тянет мобов | Наносит урон |
| Лавовая рыбалка | Можно ловить в лаве | Незерская добыча |
| Рыбацкое счастье | Шанс не потратить приманку и прочность | Сильнее |

## 3. Защита от накрутки

- **Поставленные блоки.** Сервер запоминает блоки, поставленные игроками. Их поломка не даёт опыта шахтёру, копателю и лесорубу. Поставленный песок и гравий падают и теряют отметку, поэтому для них действует счётчик: каждый поставленный блок отменяет опыт за следующий добытый блок того же вида.
- **Строитель.** Опыт только за позицию, где за последние 24 часа никто не ставил блок.
- **Автоматизация поощряется.** Механизм, созданный игроком, приносит опыт своему владельцу. Например, умная вагонетка из будущего мода рубит дерево, а опыт лесоруба получает игрок, который её сделал. Для этого у мода будет общий интерфейс начисления опыта с указанием владельца. Автоматизация приносит 50% от опыта за ту же ручную работу и только пока владелец в игре. Механизм без владельца опыта не даёт.
- **Печь и другие станции.** Без автоматизации опыт получает тот, кто забрал результат.
- **Мобы из спавнера** дают 25% опыта. Способ определить такого моба нужно проверить прототипом.
- **Творческий режим и команды** опыта не дают.
- **Повторы.** Опыт за стрижку, дойку и разведение привязан к перезарядке животного. За получение урона не более 20 опыта в секунду.

Все ограничения задаются в файле данных.

## 4. Уровни

У игрока две шкалы опыта:

| Шкала | Сколько опыта | Куда тратятся очки |
| --- | --- | --- |
| Опыт ветви, своя у каждого направления | ×1 от полученного | только в своей ветви |
| Общий опыт, одна шкала на все направления | ×0,1–0,2 от полученного, для начала ×0,15 | в любую ветвь, например чтобы догнать отстающую |

Каждый уровень шкалы приносит одно очко этой шкалы. Опыт для следующего уровня растёт: `9 × уровень^1.5`, округление вниз. Цель: около 50 часов на полную ветвь при 75 уровнях. Это расчётная оценка, её нужно проверить замером в игре. Предел уровней подбирается так, чтобы всё дерево можно было прокачать целиком. За опыт в игре выводится короткое сообщение над панелью предметов.

Смежное действие приносит опыт двум ветвям: основной ×1 и смежной ×0,8. Общая шкала считается только с основного начисления. Список хранится в файле данных:

| Действие | Основная ветвь | Смежная ветвь |
| --- | --- | --- |
| Руда сразу падает слитком (Переплавка) | Шахтёр | Кузнец, как за слиток из печи |
| Брёвна сразу падают досками (Плотник) | Лесоруб | Крафтер, как за крафт досок |
| Сбор незерского нароста | Фермер | Алхимик |
| Крафт инструмента или брони | Кузнец | Крафтер |
| Крафт еды | Повар | Крафтер |
| Убийство животного | Воин | Скотовод |
| Соединение книги и предмета на наковальне | Чародей | Кузнец |

Темп ветвей пересчитывается после обсуждения всех ветвей и проверяется замером в игре.

Уровень ветви даёт небольшую постоянную прибавку в своей сфере. Значимые эффекты находятся в дереве.

Очки можно перераспределить за обычный опыт Minecraft, цена должна быть невысокой.

## 8. Проверка среза «Шахтёр» (2026-11-10)

Мод собирается на коммите Horizon `7e4e421`, потому что хелпер `native_player_break_block` появился после Nightly 2026-11-08. Код: этот репозиторий.

Подтверждено в игре, онлайн-режим, один игрок:

| Что проверялось | Результат |
| --- | --- |
| Опыт за блоки | совпадает с таблицей |
| Неподходящий инструмент | опыта нет |
| Поставленный блок | опыта нет, в том числе после перезапуска сервера |
| Жила | до 16 блоков, останавливается на поставленном блоке |
| Переплавка и смежный опыт | слитки выпадают, Кузнец получает ×0,8 |
| Лишняя руда и Жадность | 1,23 алмаза с руды при ожидании 1,25, 100 руд |
| Прилив сил | Спешка II и скорость |
| Скорость кирки | обсидиан 193 → 180 тиков |
| Очки и окно дерева | ветвь из 74 узлов, клик тратит очко |

Нагрузка, средний тик сервера, 1 игрок, 150 блоков камня подряд (обе сборки не отладочные):

| Сборка | Простой | Камень | 25 срабатываний Жилы по 16 блоков |
| --- | --- | --- | --- |
| Без мода, Nightly fdc87ae | 2,92 мс | 2,84 мс | не мерилось |
| С модом, профиль performance, коммит 7e4e421 | 4,3 мс | 4,03 мс | 3,89 мс, разовый пик 51 мс |

Разница около 1,2 мс видна и в простое. Сборки отличаются коммитом и профилем, поэтому долю самого мода выделить нельзя. В бюджете тика 50 мс запас большой.

После ревью кода сохранение стало надёжнее, и это проверено в игре: опыт и отметки блоков записываются при немедленной остановке сервера, повреждённый профиль откладывается как `.bad`, запись идёт через временный файл, отметки ставятся только на блоки, дающие опыт.

Известные ограничения: отметка не снимается, если поставленный блок исчез без участия игрока, например от взрыва. Запись отметок на диск идёт в основном потоке сервера. Для больших баз её стоит вынести в отдельный поток.

Не проверено:

- Защита от повторного приветствия и остановка Жилы при поломке кирки: для них нужен специальный клиент или редкая ситуация, код проверен только ревью.
- Реальный темп прокачки. Бот ломает блоки медленнее человека, потому что команда ждёт подбор предметов. 50 часов на ветвь остаются расчётной оценкой.
- Несколько игроков одновременно с начислением опыта.

- Вожак работает только при Shift. Статусы Верного пса действуют и в PvP.
- Быстрая плита ускоряет только еду, бонус берётся у последнего открывшего.
- Улучшение Едока на бегу даёт Скорость. Походная кухня объединяет супы. Секретный рецепт добавляет эффекты к существующим блюдам.
- Широкий разлив действует на внешнее кольцо. Смешению нужны разные зелья в одной варочной стойке.
- За двойню опыт рождения начисляется дважды.

Ремесло:

- Быстрый разбор помнит последние 4096 своих блоков.
- Инженер возвращает ингредиенты по одному. Ткач даёт шанс на +1. Вагонетки учитывают только удары того, кто держит предмет.
- Массовый крафт повторяет Shift-клик. Подручные заполняют сетку 3×3 после крафта, поровну на клетки.
- Бонусы печи берутся у последнего открывшего. Кольчужник действует на любую броню.
- Мастер за предел берёт 39 уровней. Обновление меняет предложения при открытии, раз в 5 минут.
- Знаток пишет в чат. Книжник повышает стоимость. Перенос тратит исходный предмет. Точилка тратит книгу.

Странствия:

- Тяжёлая поступь даёт Скорость при двух и более тяжёлых частях брони.
- Возврат стрел кладёт их в инвентарь.
- Перезарядка и список мобов из спавнеров живут в памяти до перезапуска.
- Бонусы ближнего боя не действуют на Эндер-дракона.

В PvP вопреки общему правилу действуют атрибуты `max_health`, `movement_speed`, `step_height`, `luck`, а также Скорострел и скорость стрел. Владелец сервера принял это 2026-11-10.

Опыт за автоматизацию (раздел 3) приходит от модов с механизмами через консольную команду `pct-machine` (раздел 11). Обычные механизмы игры владельца не имеют и опыта не дают.

### Что проверено (2026-11-11)

Опыт проверен в игре на выделенном сервере, онлайн-режим: копание, рубка, созревший урожай, незерский нарост, строительство, крафт, печь, костёр, еда, варка, мёд, дойка, стрижка, разведение, приручение, наковальня, стол зачарования, торговля, кисточка, ближний бой, стрельба, урон от мобов, биомы, измерения, достижения, рыбалка.

Все 285 ключей эффектов проверены в игре на сборке `dev`. Каждый ключ включался отдельно через дерево в файле настроек, остальные эффекты и бонус уровня стояли на нуле, результат сравнивался с прогоном без узла. Узлы для двух игроков проверены с ботами на локальном сервере, который на это время работал без проверки аккаунтов. Рисуемое на экране (Рудный нюх, Орлиный глаз, окно дерева) проверено скриншотами. Также проверены: исключение боевых бонусов в PvP, кик клиента с другой версией протокола, опыт владельцу механизма онлайн и его отсутствие офлайн.

Ошибки, найденные и исправленные этой проверкой: Провокация не работала на сервере, контуры Рудного нюха скрывались камнем, Шеф терял вторую порцию из печи, Угощение не давало эффектов, Удар щитом не отталкивал моба, клиент не видел возвращённых семян, игроки в творческом режиме получали опыт за печь.

Оговорки:

- Морской клад работает на реальных узлах. При искусственно завышенной удаче (30 и больше) улов пропадает совсем, причина не найдена; узлами такая удача недостижима.
- Щит-стена проверена ударами через `/damage`, чтобы попасть внутрь задержки подъёма щита.
- Темп прокачки (около 50 часов на ветвь) рассчитан, но не измерен.

Известные лазейки: счётчик поставленного песка и гравия живёт только до перезапуска сервера; блок, сдвинутый поршнем, теряет отметку «поставлен игроком».

Часть событий движка срабатывает только при загруженном моде с типажом `Hooks`, поэтому мод ставит хуки прямо на функции разведения, наковальни и смерти, а приручение слушает через триггер достижения `tame_animal`. В одиночном мире хук наковальни не вызывается, опыта за неё там нет.

Дерево читается из файла только в сборке `dev`: `dev.ps1` задаёт при компиляции переменную `PCT_EXTERNAL_TREE`, потому что в профиле `dev` у лаунчера проверки отладки выключены. Сборки `performance` и `release` используют дерево, вшитое в мод.

## 10. Окно дерева (2026-11-11)

Дизайн утверждён владельцем по HTML-превью (`design/preview`) и перенесён в игру.

- **Раскладка.** Ветви разведены так, что поздние кольца не ложатся на соседние ветви и связи не пересекаются. Раскладку пишет `examples/gen_tree.rs`, проверяет `design/tools/check-tree.mjs`.
- **Ранги.** Два подряд идущих узла с одинаковым эффектом объединены в один узел с двумя рангами, таких узлов 83. В правом верхнем углу узла стоит отметка 0/2, 1/2 или 2/2. Клик добавляет один ранг, эффект растёт с рангом, следующий узел открывается только при полном ранге.
- **Сохранения.** Версия протокола поднята до 5. Старый профиль сохраняет опыт по всем ветвям, но изученные узлы сбрасываются.
- **Иконки.** У каждого узла своя пиксельная иконка 16×16 в стиле ванильного Minecraft. Исходники лежат в `design/icons/*.json`, правила стиля в `design/icons/STYLE.md`. Игра берёт их из атласа `data/atlas.png`, который собирает `design/tools/game-atlas.mjs`.
- **Цветовые зоны.** У каждой ветви свой цвет фона, вместе они образуют цветовой круг.
- **Частицы.** По изученным связям от центра к следующему узлу бегут частицы. На неизученных связях их нет.
- **Подписи веток.** Игровой шрифт шире, чем в превью. Ближние к центру подписи стоят на своих местах, а каждая следующая сдвигается от центра, пока не перестанет задевать уже поставленные.

Отличия от превью: игровой шрифт Minecraft вместо Tiny5, виньетка блоками по 16 пикселей, наведение на узел подсвечивается светлой заливкой.

## 11. Опыт от машин других модов (2026-11-11)

Мод с механизмами (RustCraft) сообщает о действиях своих машин консольной командой `pct-machine <отчёт>` через `native_run_mod_command`. Без Path-of-craft-tree команда неизвестна и тихо не выполняется, поэтому моды не зависят друг от друга при сборке. Игрок, даже оператор, отправить отчёт не может: слушается только консольный путь.

| Отчёт | Что делает мод |
| --- | --- |
| `break <владелец> <измерение> <x> <y> <z> <блок> <инструмент>` | Поставленный блок теряет отметку и опыта не даёт; иначе владелец получает долю опыта за этот блок с этим инструментом |
| `place <измерение> <x> <y> <z> <блок>` | Блок, поставленный машиной, отмечается как поставленный игроком |
| `smelt <владелец> <предмет> <количество>` | Доля опыта за еду или слитки, как из своей печи |
| `craft <владелец> <рецепт> <предмет> <количество> <крафтов>` | Доля опыта за крафт, без награды за первый крафт |
| `kill <владелец> <id сущности> <тип моба>` | Доля опыта за убийство из лука, с урезанием за мобов из спавнера |
| `fish`, `milk`, `build`, `chunk`, `biome`, `structure` | Доля опыта Рыбака, Скотовода, Строителя и Исследователя по тем же правилам и с той же памятью, что у игрока |
| `repair`, `breed`, `shear`, `honey`, `brush`, `brew`, `enchant` с количеством | Доля опыта за поштучную работу в ветках Кузнеца, Скотовода, Копателя, Алхимика и Чародея |
| `slaughter <владелец> <id сущности> <тип животного>` | Доля смежного опыта Скотовода, как за убийство животного игроком; Воину и Стрелку ничего |
| `shot <игрок> <id сущности> <тип моба>` | Полный опыт Стрелка игроку, чьё оружие из мода с машинами убило моба |

С этими отчётами (добавлены 2026-11-11 по запросу RustCraft) машины могут качать все ветки, кроме приручения: оно остаётся за игроком. Форматы и правила — в `docs/machine-reports.md`.

Правила:

- Доля опыта машин — поле `machine_share` в `data/tree.json`, по умолчанию 0,5.
- Опыт получает только владелец, который на сервере.
- Эффекты дерева владельца на машины не действуют.
- Разбор отчётов лежит в `machine_rules.rs` и покрыт тестами, применение — в `machines.rs`.

Решения владельца (2026-11-11):

- Убийство турелью или стражем засчитывается ветке Стрелка.
- Опыт за слитки идёт за каждый слиток, в том числе за удвоенные дробилкой.
- Разрушитель блоков и бур-проходчик опыта не дают.
- Дневного потолка опыта от машин нет.

Форматы и правила для любых модов с машинами — в `docs/machine-reports.md`. Как машины RustCraft сопоставлены с отчётами — в его репозитории: `docs/design/path-of-craft-tree-contract.md`.

## 13. Вместе с другими модами сборки (2026-11-12)

В сборке сервера, кроме дерева, RustCraft, SoulsCraft и интерфейсные моды: JEI, карта мира, Mouse Tweaks, BetterF3. Всё собирается на одном коммите Horizon `7e4e421` и проверяется вместе на общем стенде `horizon-joint-dev`.

- **Клавиши.** Чутьё сокровищ перенесено с N на I: N у карты мира включает миникарту. Все семь клавиш дерева переназначаются в «Настройки» → «Моды» → кнопка «Настройки» рядом с Path-of-craft-tree (`keys.rs`). H и J по умолчанию совпадают с клавишами карты мира, каждый игрок разводит их сам.
- **Боевая сводка.** На каждом игроке лежит `pct:summary`: уровни и рабочие ранги Воина, Стрелка и Стража с их пределами. По ней SoulsCraft подстраивает силу мобов, владелец одобрил это 2026-11-12. Формат — в `docs/combat-summary.md`.
- **Опыт за усиленных мобов** (2026-11-13, v0.4.6). Метка `pct.xpNNN` на мобе умножает опыт за его убийство на NNN%, от 1 до 500. SoulsCraft ставит её усиленным мобам: ×(1 + 0,5·(hp_mult − 1)), гипотеза Г3 SoulsCraft, одобрена владельцем.
- **Мобы SoulsCraft в таблице здоровья** (2026-11-13, v0.4.9). Опыт за убийство считается от здоровья вида моба, для незнакомого вида — 20. Виды SoulsCraft внесены по её `data/mobs.json`, SoulsCraft присылает новые числа при изменениях (`docs/combat-summary.md`).
- **Посещённые чанки** (2026-11-13, v0.4.8). Компактный двоичный файл с дописыванием новых чанков вместо JSON, сохраняемого целиком. Замеры ботами — в разделе «Посещённые чанки» `docs/perf-log.md`.
- **Trait-мод SoulsCraft.** Если SoulsCraft станет trait-модом, охраняемые хуки Horizon начнут срабатывать. Проверено по коду 2026-11-13: дважды PCT ничего не заплатит, наковальня, разведение и убийства идут каждое одним путём.
- **Самотест.** Консольная команда `pct_selftest run` проверяет все отчёты машин и метку `pct.xpNNN` на настоящем мобе: 25 сценариев, эталон считается из `tree.json`. Её запускает `joint.ps1 check` стенда. `pct_selftest summary` печатает сводку игроков.
- **Записи LetsCam.** При просмотре записи сообщения мода приходят клиенту снова. Обработчики только обновляют состояние клиента, поэтому это безопасно. После просмотра окно дерева показывает профиль из записи до следующего сообщения сервера.
- **Сборка клиента.** Лаунчер сначала собирает клиента на базовом коммите окружения (Nightly `fdc87ae`), где дерево не собирается, и только потом на `7e4e421`. Флага, который это отключает, нет. Лишний заход уйдёт, когда выйдет Nightly не старше `7e4e421`.
