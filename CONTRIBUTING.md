# Как помочь проекту

Спасибо за интерес к Path-of-craft-tree. Сообщения об ошибках, идеи по балансу и пулл-реквесты принимаются на русском и на английском.

## Ошибки и идеи

- **Ошибка:** откройте [issue по шаблону](https://github.com/Betreazen/path-of-craft-tree/issues/new/choose). Укажите версию мода, коммит Horizon и шаги. Строки журнала с `path_of_craft_tree` очень помогают.
- **Баланс:** числа в дереве — гипотезы, их проверяют плейтестом. Напишите, сколько часов уходит на ветвь у вас и откуда идёт опыт: страница «Статистика» в окне дерева показывает лучшие источники за сессию.

## Код

Нужны Rust (stable, edition 2024) и, для проверки в игре, [лаунчер Horizon](https://github.com/horizon-rust/horizon).

```powershell
cargo test                                         # правила, без сборки игры
cargo clippy --all-targets -- -D warnings -A dead_code
cargo run --example gen_tree                       # пересобрать data/tree.json
.\dev.ps1 both                                     # собрать клиент и сервер мода
```

Правила проекта:

- **Код правил не зависит от игры.** Всё, что можно проверить тестом, живёт в модулях без `Game`, а модули с `Game` только передают события. Новое правило приходит с тестом.
- **Номера старых узлов не меняются.** Новые узлы только дописываются в конец. Сохранённые профили и строки сборок ссылаются на номера, это проверяет тест `appended_nodes_keep_the_old_numbering`.
- **Баланс в данных.** Числа опыта и узлы задаёт `examples/gen_tree.rs`, а не код мода.
- **Каждый текст — на двух языках.** Русский — в коде и в дереве, английский — в `mixins/path_of_craft_tree/data/en-*.json`. Тест `every_text_of_the_shipped_tree_has_its_english` не пропустит узел без перевода.
- **Горячие пути под бюджетом.** Изменения в тике игрока, в разрушении блока и в окне дерева сверяйте с [docs/perf-spec.md](docs/perf-spec.md).
- Исходники модулей мода начинаются с `//`, а не с `//!`: так требует сборщик Horizon.

Устройство мода, все ветви и решения по балансу описаны в [docs/design.md](docs/design.md).
